# ЭКОВЕР — стартовый проект

Учебный каркас для проверки потока CSV → FastAPI → React. Включает загрузку CSV, базовую проверку, просмотр первых строк и временную заглушку для ML.

## Запуск backend (Linux)
Из корневой папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --reload
```

Откройте http://127.0.0.1:8000/docs

## Запуск frontend
В отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173. Нужны Node.js и npm.

## Проверка
1. Запустите backend и frontend.
2. В интерфейсе выберите CSV и нажмите «Загрузить и проверить».
3. Выберите файл и нажмите «Показать данные».
4. Проверьте число строк, столбцы, пропуски и первые 10 записей.
5. Кнопка проверки анализа пока вызывает заглушку — ML ещё не подключён.

## Ограничения
- Файлы сохраняются локально в `data/uploads`; это не настоящее Data Lake.
- CSV в `data/raw` считается исходным; не изменяйте оригинал.
- Проверка CSV базовая, не подтверждает научную корректность.
- Water Potability подходит для анализа/классификации Potability, но не содержит парных показаний бюджетного и эталонного датчиков для доказательства коррекции показаний.
- Перед интеграцией согласуйте с командой способ доступа к Data Lake и контракт ML API.
- Не используйте учебный проект для решений о безопасности питьевой воды.
